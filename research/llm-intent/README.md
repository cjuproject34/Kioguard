# KioGuard 의도분류·온디바이스 LLM 연구

정리일: 2026-09-27. 이 폴더는 지금까지 작성한 설계·검토 문서와 기존 실험의 검토 자료를 보존합니다.

## 목표와 현재 상태

모든 서비스 AI 추론은 온디바이스에서 수행합니다. 사용자 발화의 영향도와 의미 해석 복잡도에 따라 LLM과 검증된 규칙의 역할을 나누고, 오류 대응·모델·양자화·토큰 최적화로 정확도와 모바일 자원 효율을 함께 평가합니다.

**현재는 기존 실험 감사와 의도 체계 개정, 모델·PTQ·QAT 실험 설계를 마친 단계입니다.** 신규 실험은 아직 실행하지 않았습니다. 최신 사용자 결정과 환경 선택은 [STATUS.md](STATUS.md)를 우선 확인하세요.

## 기존 결과를 해석하는 기준

| 항목 | 확인된 내용 | 한계 |
|---|---|---|
| Rule | 분리한 함수의 검산 45/48 | 새 모델 추론 결과가 아님 |
| Q4 | 저장 예측 41/48 | 전체 raw 생성문을 독립 재채점한 결과가 아님 |
| f16 GGUF | 저장 예측 37/48 | Q4와의 차이를 양자화만의 효과로 단정하지 않음 |
| Hybrid | Rule과 저장 Q4 예측을 조합한 재구성 47/48, 호출 대상 2/48 | 원본 Hybrid 실험의 재실행이 아님 |
| QAT | 이전 노트북에서 학습·변환·평가 증거 미확인 | 학습 CSV 파일명이 QAT 수행 근거가 되지 않음 |

기존 48행은 개발·회귀 자료이며 독립 test가 아닙니다. `data/baseline/gold_audit.csv`는 **기존 8개 라벨 체계의 원본 정답**입니다. v1.2의 새 의미 정의로 덮어쓰지 않았습니다. `train_audit.csv` 역시 재검수 전 과거 자료이며 바로 새 QAT 학습에 투입하지 않습니다.

## 포함 범위와 재현성

- 문서 12개와 선택한 근거 자료는 작업 당시 파일을 그대로 복사했습니다. [보존 manifest](evidence/snapshot_manifest.json)에 상대 경로·크기·SHA-256을 기록합니다.
- `audit_counts.json`, `static_audit_results.json`은 당시 검산 결과입니다. `q4_final.json`, `f16_final.json`은 과거 저장 출력에서 추출한 예측입니다. `intent_v12_verification.json`은 문서·행 보존 검사이며 모델 평가가 아닙니다.
- 원본 PDF·DOCX·XLSX, Drive 노트북 전체, 비공개 인증정보, 모델 가중치, 임시 추출 로그·이미지는 이번 업로드에 포함하지 않았습니다. 문서에 남은 Drive 링크의 접근 권한은 별도입니다.
- 이 저장소만으로 과거 모델 실행 환경을 완전히 재현할 수 있다고 주장하지 않습니다. 원본 revision과 일부 raw 결과가 없다는 한계를 검토보고서에 유지합니다.

문서에 포함된 과거 회의 제안과 이전 목표 수치는 현재 확정 사항 또는 달성 결과와 구분해서 읽어야 합니다.
