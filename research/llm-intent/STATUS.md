## 현재 결정

- 현재 화면을 새로 읽는 음성 명령과 도움 세션 종료 음성 명령은 **보류**합니다. 현재 평가 의도에 임의 추가하거나 영구 미지원으로 라벨링하지 않습니다.

- ‘화면을 못 찾겠어요’와 ‘번호표 뽑는 거 알아요’는 지정된 재질문을 합니다. ‘취소하고 다시 처음부터 할게요’는 현재 주문 취소 후 첫 화면 이동으로 해석합니다.

## 다음 순서

1. 평가 166건을 사람 검수하고 수정·제외 사유를 기록합니다.
2. 완료된 8개 후보 재평가를 baseline으로 보존하고, PTQ는 Qwen3.5 2B Q8_0·Q4_K_M gate부터 실행합니다. Gemma 3 1B는 FP16 오류가 커 PTQ를 보류합니다.
3. 현재 gate 결과에는 통과 모델이 없으므로 118건 확장 전에 오류 원인을 검토하고, 구조화 출력 제약 또는 prompt 수정 여부를 결정합니다.
4. PTQ 도구체인 확인은 완료했습니다. Qwen3.5 2B는 변환·양자화·GGUF 단일 생성까지 완료했고, Gemma4는 Colab RAM 제한으로 변환이 중단됐습니다.
5. 호환성이 확인된 후보에서 FP16 기준 → Q8_0 → Q4_K_M을 비교하고, Gemma 4는 Q4_0 공개 QAT 산출물 비교를 별도 실험으로 둡니다.
6. PTQ 전후 동일 gate를 채점해 양자화로 새로 생긴 오류만 분리합니다. 고영향 오류가 악화되면 해당 bit를 중단합니다.
7. PTQ에서만 발생한 회귀가 확인될 때 QAT 파일럿으로 이동합니다. QAT가 FP16 자체 오류를 해결한다고 가정하지 않습니다.
8. 최종 후보가 좁혀진 뒤 S24 Ultra에서 로딩·반복 추론·메모리·지연·발열을 측정합니다.

최종 모델, 양자화 규격, 정확도 목표, 허용 지연·메모리 예산은 아직 실측으로 확정하지 않았습니다. 공개 QAT 모델 사용과 직접 QAT 수행은 별도 성과로 기록합니다.
