# 현재 결정과 다음 작업

기준일: 2026-09-27. 과거 문서를 수정하지 않고 이후의 사용자 결정과 진행 상태를 기록합니다.

## 현재 결정

- 현재 화면을 새로 읽는 음성 명령과 도움 세션 종료 음성 명령은 **보류**합니다. 현재 평가 의도에 임의 추가하거나 영구 미지원으로 라벨링하지 않습니다.
- 핵심 의도 정의는 v1.2의 14개 구성입니다. 재질문·판정 보류는 정상 대응에 포함합니다. 새 평가셋의 최종 동결은 아직 완료하지 않았습니다.
- ‘따뜻한 걸로 두 잔이요’는 선택 상품 옵션, ‘처음으로 돌아가주세요’는 첫 화면 이동으로 처리합니다.
- ‘화면을 못 찾겠어요’와 ‘번호표 뽑는 거 알아요’는 지정된 재질문을 합니다. ‘취소하고 다시 처음부터 할게요’는 현재 주문 취소 후 첫 화면 이동으로 해석합니다.
- 새로운 모델 선정·PTQ·QAT 연구 단계로 이동했습니다. 기존 Colab 결과는 baseline으로 보존합니다.

환경 선택 권고는 **Colab 중심 실험 + 로컬 관리 + 휴대폰 실측**입니다. RX 580은 확인한 AMD 공식 ROCm 지원 목록에 포함되어 있지 않아 주력 GPU 학습 환경으로 권하지 않습니다. CPU 기반 PTQ나 Vulkan 추론 가능성과 직접 QAT 지원은 구분합니다. [AMD 공식 호환성 표](https://rocm.docs.amd.com/en/latest/compatibility/compatibility-matrix.html), [llama.cpp 빌드 문서](https://github.com/ggml-org/llama.cpp/blob/master/docs/build.md).

서비스 중 온디바이스 추론과 개발 단계의 Colab 학습·변환은 서로 다른 범위입니다. Colab의 GPU 배정과 실행 시간은 변동될 수 있으므로, 무료 환경에서 본 QAT가 가능하다고 미리 확정하지 않습니다. [Colab 공식 FAQ](https://research.google.com/colaboratory/faq.html).
