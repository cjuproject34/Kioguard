## 1. 원본·새 기준·사용자 지정의 구분

ID·원문·V1 정답은 기존 보존본의 48행을 그대로 유지했다. 새 의도와 대응, 영향도·복잡도는 별도 열로 기록했다. 새 기준에 맞춰 기존 정답이나 과거 점수를 덮어쓰지 않았다. 이번에는 Drive의 최신본이나 실제 과거 화면을 재조회·복원하지 않았다.

판정 상태의 뜻:

- **사용자 지정:** 이번 대화에서 사용자가 해석 또는 기대 대응을 정한 행. 적용 대상은 FD-03·FD-08·FD-22·FD-24·GV-09·GV-19·GV-20의 7행이다.
- **단일 후보:** 현재 제공된 발화에서 특정 의도를 제안할 수 있는 행. 필요한 대상·화면 검증과 사람 검수는 별도다.
- **문맥 의존:** 직전 질문·단계 등에 따라 의도가 달라져 조건부로 기록한 행.
- **판정 보류:** 문장 자체의 해석이 갈리며 추가 질문이 필요한 행.

의도와 영향도는 다르다. 의도가 정해져도 실제 안내 결과를 판단할 단계·상태가 없으면 영향도는 U다. 아래 복잡도는 **원문과 현재 제공된 문맥을 기준으로 한 잠정 등급**이며, 실제 대상 연결의 복잡성이 확인되면 재평가한다. C1이라는 이유만으로 Rule 처리 승인을 뜻하지 않는다.

| FD-22·GV-19 | 첫 화면 이동을 뜻한다는 사용자 기준 | 시나리오에 화면 이동 목표를 명시. 원문만으로 모든 상황에서 HOME이 유일한 뜻이라고 주장하지 않음 |
| FD-24·GV-20 | 화면 대상을 묻는 것이 정답 대응 | 정답은 적절한 대상 질문. GUIDE/HELP 중 하나를 맞혔다는 이유만으로 성공 처리하지 않음 |
| GV-09 | 안내를 원하는지 묻는 것이 정답 대응 | 정답은 목적 확인 질문. 단순 INFO 분류나 일방적 안내만으로 성공 처리하지 않음 |

사용자 기준은 이 버전의 사례 정의에 반영한다. 평가 시 필요한 문맥을 모델에는 제공하지 않고 평가자만 사용하여 오답을 만드는 방식은 사용하지 않는다.

## 5. 등급 변경과 남은 검수

v1.0에서 ‘지시어·부정·변경 동사’에 따라 높아졌던 복잡도 일부를 새 기준으로 다시 정리했다. 예를 들어 명확한 ‘등본 말고 초본’은 C2, 직접적인 위치 문의는 원문 기준 C1로 기록한다. PIN 입력 위치 문의는 문장이 단순해도 영향도 H다. 낮아진 잠정 복잡도가 정확도 개선이나 처리 시간 단축을 뜻하지 않는다.

영향도의 가능한 범위를 단일 정답처럼 사용하지 않도록 기존 `U→M/H` 표기는 U로 정리했다. 화면·단계·동작 효과를 확보하면 구체적인 결과를 근거로 H/M/L을 부여한다. 사용자께서 의도를 정해 주신 행도 운영 문맥이 없으면 U가 남을 수 있다.

원문 48행은 문자열 기준 38개 고유 발화다. 동일·유사 표현을 학습과 독립 평가에 흩어 넣지 않는다. 사용자 지정 문맥과 새로 설계한 문맥은 실제 과거 수집 문맥과 구분한다.

I06·I13·I14 등의 명확한 적용 사례와 거절·조건부 요청·직원 도움·범위 밖 사례는 별도 보강이 필요하다. I08은 이번 사용자 기준에 따라 FD-08의 복합 요청에 포함되지만, 이 한 사례만으로 취소 의도 성능을 평가할 수 없다.

이번에 완료한 것은 문서 수정과 원문 대조다. 신규 모델 예측, 독립 검수자 간 합의, 모바일 성능 측정은 수행하지 않았다.
